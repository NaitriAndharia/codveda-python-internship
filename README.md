# Codveda Python Internship - 6 Tasks

Welcome to my Python Development Internship repository with **Codveda Technologies**. This repository contains all the 6 assigned tasks implemented cleanly in Python.

## 🚀 Projects Included

1. **Calculator** (`calculator.py`) - A basic command-line calculator performing arithmetic operations.
2. **To-Do List** (`todo.py`) - A task management script to add, view, and delete daily tasks.
3. **Number Guessing Game** (`number_guessing_game.py`) - An interactive game where users guess a randomly generated number.
4. **N-Queens Visualizer/Solver** (`n_queens.py`) - A classic algorithmic solution solving the N-Queens puzzle using backtracking.
5. **File Encryption & Decryption** (`file_encryption.py`) - A security utility tool to encrypt and decrypt text files securely.
6. **API Integration** (`api_integration.py`) - A script that fetches and displays live data from a public API.
